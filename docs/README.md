# kah documentation

kah adds source-linked intent tracking and review to native coding-agent sessions.

[Interactive launch](interactive.md) describes launch options and execution
policy. [Daily commands](COMMANDS.md) lists the available commands.

- [Setup policy](setup.md): shared setup, hooks, MCP networking and tool credentials.
- [Claude execution](claude-adapter.md): host controller, permissions and reminder delivery.
- [User controls](user-controls.md): steering, commentary, ledger review and message receipts.
- [Relays and dispatch](relay.md): source-verified quotes and inherited requirements.
- [Unattended work](unattended.md): worktrees, verification, controls and resume.
- [Startup and transport](startup-modes.md): overlays, session history and live delivery routes.
- [Overlay recovery](codex-overlay-recovery.md): shared-file repair and recovery errors.
- [Observer judgments](judge-backends.md): Jev answers, context preparation and decision thresholds.
- [Component maps](component-map.md): change attribution and cached review evidence.
- [Dependency notes](dependencies.md): manifests, the lockfile and `make audit`.
